WOOBIE'S MISSION CONTROL - WINDOWS QUICK START
==============================================

VERSION 0.7.4

This build uses the desktop launcher and serves the compiled React dashboard
from http://127.0.0.1:8090/. Node.js and Vite are not required.

1. KEEP THE COMPLETE PACKAGE TOGETHER

   Extract the complete ZIP somewhere outside KSP's GameData folder. Do not
   place the release folder anywhere under GameData: KSP loads DLLs from nested
   folders and can treat the packaged service DLLs as duplicate installations.

   Keep the extracted Dashboard and GameData folders next to one another. The
   launcher can then install or repair these services:

     WoobiesControlStats
     KRPC.StageStats
     KRPC.SystemHeat
     KRPC.WoobiesMechJeb

   The kRPC KSP mod is required. Other supported mods enable optional panels.

2. SET UP AND START THE DASHBOARD

   Open this package's Dashboard folder and double-click:

     Start KSP Dashboard.bat

   On the first run, choose Dashboard + ESP32 Controlpad, Dashboard only,
   ESP32 Controlpad only, or Exit. Use Up/Down and Enter, or type 1-4 and press
   Enter. The launcher creates an isolated .venv folder and downloads only the
   Python packages for the component(s) you selected. Dashboard-only setup
   does not install pyserial. It does not add, upgrade, or remove packages in
   your system Python.

   Both component sections remain in the launcher. If you skipped one, its
   Start-button position says Set up; click it later to add that component's
   dependencies to the same isolated .venv.

   Python 3.14 is required for this release. If it is not installed, the
   launcher provides the official download address and can be run again after
   Python is installed.

   UPDATES: The first release that includes managed updates must still be
   downloaded and extracted once as a complete ZIP. After that, a newer
   verified release shows Review & install in this window. Mission Control
   downloads the smaller runtime-update asset, lets you review its notes and
   local managed-file changes, and changes nothing until you choose Install
   and restart. It preserves this package's .venv, logs, settings, README,
   gallery, and unknown files. It may refresh only the service repair copies
   inside this package; it never updates the selected live KSP GameData folder.
   If verification, the health check, or restart fails, the updater restores
   the previous managed files and retries recovery before the next normal
   launch. View release remains available for a manual full-ZIP update.

3. SELECT KSP AND INSTALL THE SERVICES

   Before starting KSP, choose the main Kerbal Space Program installation
   folder in the launcher's KSP installation section. Select the folder that
   contains GameData, not GameData itself.

   Review the Mission Control KSP services panel. If any service says Missing
   or repair ready, choose Install / Repair and confirm the listed changes.
   Amber "current - not in package" statuses mean the installed DLL version is
   already current but this copy of Mission Control cannot provide a repair;
   missing or outdated installed DLLs are shown in red.
   Existing service DLLs are backed up and each installed copy is verified.
   No other GameData files are changed.

4. CONNECT TO KSP

   Start KSP and load a save. The main menu is not enough: kRPC keeps its
   servers stopped while no game is loaded. Enter Space Center, the VAB/SPH,
   Tracking Station, or Flight, then confirm the server auto-started (or start
   it manually).
   Keep kRPC on address 127.0.0.1, RPC port 50000, and Stream port 50001. Port
   8090 belongs to Mission Control's local React dashboard and browser feed,
   not to kRPC.

   Review the launcher's KSP & kRPC compatibility panel. It checks the selected
   KSP version, duplicate or misplaced core DLLs, installed kRPC,
   Woobie's MechJeb bridge and MechJeb 2 versions, plus kRPC's saved server
   settings. If Review fixes appears, open it for the observed mismatch,
   required or tested value, and the suggested service-repair, kRPC, or CKAN
   correction.

   Choose Test connection after the save is loaded and the kRPC server is
   running. It confirms that kRPC responds and that services for the installed
   integration DLLs are registered.
   In the Mission Control launcher, start Dashboard feed (telemetry + React).
   With LAN access off, the launcher waits for the loopback server and opens
   the dashboard in your browser automatically. Each tool stops after 10
   failed kRPC attempts (about 20 seconds) instead of retrying forever. Its
   connection status then turns amber and recommends Test connection.

   OPTIONAL TRUSTED-LAN ACCESS: Leave Allow local network access off unless
   every device on the selected network is trusted. Choose an active private
   IPv4 address from the LAN address list; Refresh rescans the host and Copy
   LAN URL copies the address for a second device. Turning LAN access on opens
   a warning that explains the listener has no authentication or encryption.
   LAN peers can view telemetry, finances, contracts, Notes, and vessel data,
   and can issue every dashboard command, including vessel recovery or
   termination, system controls, and maneuver-node creation. Choose Cancel to
   leave LAN access off. The Remember checkbox is off by default; without it,
   the warning returns every time LAN access is turned on.

   Enabling, disabling, or changing the LAN address stops a running Dashboard
   feed. Click Start again, then use the copied LAN URL from the trusted device.
   Start does not automatically open a browser on the host while LAN access is
   enabled; choose Open dashboard if you also want a local loopback tab at
   http://127.0.0.1:8090/. If Windows shows
   a firewall prompt, allow access on Private networks only. Mission Control
   does not create firewall rules. Never forward port 8090 through a router or
   expose it on a public network, and verify the chosen adapter on VPN or
   multi-network computers.

   In Space Center and Tracking Station scenes, Mission Control shows a
   read-only program overview with save-mode-appropriate economy totals,
   filterable tracked vessels and roster, active contracts, and a combined
   Stock/Kerbal Alarm Clock alarm list. WoobiesControlStats supplies the full
   roster and stored-science extension and repairs the optional KAC kRPC bridge
   after its API becomes ready; use Install / Repair and restart KSP if either
   section is unavailable. The installer backs up and removes the two
   superseded KRPC.MissionOverview and KRPC.VesselScience DLLs automatically.
   It also backs up and removes the upstream GameData\kRPC\KRPC.MechJeb.dll
   before installing KRPC.WoobiesMechJeb, preventing duplicate MechJeb service
   registration.

   MISSION PLANNING: The left rail opens Delta-V and Resonant Orbit planners in
   Mission Control, the VAB/SPH, and Flight. Saved plans are shared through the
   local Mission Control feed. Transfer calculations are read-only until
   Flight, where creating a maneuver requires a preview and a separate
   confirmation. Mission Control never executes the node, warps, steers,
   stages, or changes throttle.

   OPTIONAL NOTES INTEGRATION: The launcher checks for zer0Kerbal's Notes
   (Kollege Ruled) v0.17.0.0, the release tested with Mission Control. When the
   mod is detected at the selected KSP location, a Notes button appears in the
   dashboard during flight and opens the active vessel's ship log in a
   right-side drawer. Select any saved note and choose Pin to flight to show it
   in a scrollable final flight panel. Use A- and A+ in either Notes view to
   adjust text size; click the size value to return to the default.

   SETTINGS RAIL: The Settings rail groups browser-local Preferences, known
   Features & Mods, curated external Help links, and About information.
   Preferences controls Kerbin/Earth time, Science alarm defaults, and hidden
   panel restoration. It also offers Mission Control Dark, Daylight Console,
   Warm CRT, and Green Phosphor color themes; the selected colors apply
   immediately and persist in the browser without changing layout or type.
   About reports the active theme. Features & Mods reports dashboard-wide status from the configured
   KSP installation, independent of the current game scene: Available,
   Available - Stock, Unavailable, or Detection unavailable. Expanded rows show
   the fixed known integration checks behind the result. This is not an
   arbitrary inventory of installed mods.
   Setup, KSP-folder selection, service Install / Repair, package updates, and
   Dashboard feed start/stop remain launcher tasks in
   Dashboard\Start KSP Dashboard.bat; the browser does not write the selected
   live KSP GameData.

For component choices, compatibility information, troubleshooting, and ESP32
control-pad instructions, see README.md.
